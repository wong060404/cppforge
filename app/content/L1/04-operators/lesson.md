# 運算子與優先序

`1 + 2 * 3` 是 7 不是 9 —— 這不是 C++ 的特性，是你小學學過的優先序。
但 C++ 有幾個**其他語言沒有**的陷阱，這一節專門處理它們。

## 優先序（記這幾層就夠）

```
高  ()                      括號
    !  ++  --  (單元)        否定、遞增
    *  /  %                 乘除、取餘
    +  -                    加減
    <  <=  >  >=            比較
    ==  !=                  相等
    &&                      且
    ||                      或
低  =  +=  -=  …            賦值
```

記不住沒關係，但有兩件事必須記住：

1. **比較在算術之後** → `a + 1 > b` 等於 `(a + 1) > b`。
2. **`&&` 在 `||` 之前** → `a || b && c` 等於 `a || (b && c)`。

不確定就加括號。**可讀性比省字元重要。**

## 陷阱一：C++ 沒有連鎖比較

```cpp
if (0 < x < 10) { }     // ❌ 幾乎永遠成立
```

它會被解析成 `(0 < x) < 10`：`0 < x` 先得到 `bool`（true=1 / false=0），
再拿 `1 < 10` → true。所以只要 `x > 0` 就成立，`x = 999` 也會過。

```cpp
if (0 < x && x < 10) { }   // ✅
```

## 陷阱二：累乘的起始值

```cpp
long long pow(int a, unsigned b) {
  long long r = 0;        // ❌ 之後怎麼乘都是 0
  for (unsigned i = 0; i < b; ++i) r *= a;
  return r;
}
```

加法的單位元素是 `0`，乘法的單位元素是 `1`。這個錯在算階乘、算次方時最常見。

## 陷阱三：`x % 2` 是 int，不是 bool

```cpp
bool is_even(int x) { return x % 2; }      // ❌ 奇數回 true
bool is_even(int x) { return x % 2 == 0; } // ✅
```

## 遞增：`i++` 與 `++i`

```cpp
int i = 0;
int a = i++;   // a = 0，i 變 1（先用再加）
int b = ++i;   // i 變 2，b = 2（先加再用）
```

在 `for (int i = 0; i < n; ++i)` 裡兩者結果一樣（因為沒人用回傳值），
但 `++i` 少一次複製，慣例上優先寫它。

## 短路求值：順序決定安全

```cpp
if (p != nullptr && p->ready()) { }   // ✅ 先擋空指標
if (p->ready() && p != nullptr) { }   // ❌ 第一件事就解參考了
```

`&&` 左邊為 false 時，右邊**不會被求值**。這是 C++ 裡「用順序換安全」的標準寫法。

## 你要實作的部分

```cpp
long long int_pow(int a, unsigned b);   // a 的 b 次方（b >= 0）
int  max3(int a, int b, int c);         // 三個整數的最大值
bool in_range(int x, int lo, int hi);   // x 是否在 [lo, hi] 內（含邊界）
```

起始碼三個地方漏了：`int_pow` 起始值是 0、`max3` 的三段式寫法在 `a > b` 時漏掉一個值、
`in_range` 用嚴格比較把邊界排除了。
