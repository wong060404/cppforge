# 即時練習全部改成選擇題

> 版本 v0.1 · 使用者要求：「題目不要出開放的打字題，全部變成有選項的」

---

## 1. 改了什麼

| 項目 | 改前 | 改後 |
|---|---|---|
| 練習題型 | 44 選擇（下拉選單）+ **25 打字題** | **69 題全部選擇**（可點選項） |

## 2. 25 題怎麼轉的

不是機械轉換。每一題都重新設計**誘答選項**，讓錯的選項對應「常見誤解」：

| 題目 | 正確 | 誘答（刻意選的誤解） |
|---|---|---|
| `int y = -7 / 2;` 是多少？ | `-3` | `-4`（以為是向下取整）、`-3.5`（以為會保留小數）、`-2` |
| `v.size() - 1` 的型別？ | `size_t` | `int`（最常見的錯）、`long`、`unsigned char` |
| 只想讀大物件不想複製，參數宣告？ | `const T&` | `T`（會複製）、`T&`（能改）、`const T* const` |
| 累乘的起始值？ | `1` | `0`（乘法單位元素搞錯，會永遠得 0）、`-1`、第一個元素 |
| `Counter` 的不變式？ | `0 <= value <= max` | `value >= 0`（漏上限）、`value <= max`（漏下限）、`value != max` |
| `std::move` 之後來源狀態？ | 有效但未指定 | 完全銷毀、一定是空的、變成 nullptr |
| `operator+=` 該回傳？ | `Vec2&` | `void`、`Vec2`（值，無法鏈式）、`const Vec2&` |

完整 25 題的清單見 git diff（`app/content/*/*/node.json` 的 `drills`）。

## 3. 順手修掉三個真 bug

### （1）L3.04 的題目**永遠答不對**

```json
"choices": ["編譯比較快", "因為編譯器必須在**使用處**看到定義才能具現化", "只是習慣", "為了避免重複定義"],
"answer":  "因為編譯器必須在使用處看到定義才能具現化"
```

選項有 `**粗體**` 記號、答案沒有 → 字串比對永遠不相等。
而且 `<option>` 不渲染 Markdown，學員看到的是帶星號的原文。

### （2）所有選項裡的 Markdown 都會原樣顯示

`<option>` 只能是純文字。像 `` `(a + b) / 2` `` 會顯示成含反引號的字串。
已清掉 5 題的 26 個選項中的 Markdown 記號（**只移除成對的 `**` 與反引號**，
`INT_MAX`、`*this`、`const T* const` 這些 C++ 原文不動）。

### （3）打字題時代的作答指示

`（用一句話說明）`、`（寫出完整數值）`、`（用一個詞回答）` 這些在選擇題裡變成噪音，
而且有些會洩漏答案（例如「（不是 0）」直接淘汰一個選項）。改寫了 11 題的題目敘述。

## 4. UI：下拉選單 → 可點選項

原本選擇題是「下拉選單 + 檢查按鈕」（要點兩次，而且選項藏在選單裡）。
既然 69 題全是選擇題，改成直接點：

```
┌────────────────────────────────────────────┐
│ 3. `int y = -7 / 2;` 之後 `y` 是多少？      │
│ ┌────────────────────────────────────────┐ │
│ │ -3                                     │ │ ← 點這裡
│ ├────────────────────────────────────────┤ │
│ │ -4                                     │ │
│ ├────────────────────────────────────────┤ │
│ │ -3.5                                   │ │
│ ├────────────────────────────────────────┤ │
│ │ -2                                     │ │
│ └────────────────────────────────────────┘ │
│ 正確 ✓                                     │
│ 整數除法向零截斷：-3.5 → -3（不是 -4）…    │
└────────────────────────────────────────────┘
```

行為：
- 點錯 → 該選項標紅 + 「再想想」，**可以繼續試**
- 點對 → 標綠 + 顯示解說 + **所有選項鎖住**（避免亂點）
- 鍵盤：`Tab` 移動、`Enter`/`Space` 選取（原生 `<button>`）

## 5. 永久防線：內容 lint 五條新規則

```
XX: drills[0] 是開放式打字題；請改成 kind: "choice" 並提供選項
XX: drills[1] 的 answer 不在 choices 裡（這題永遠答不對）
XX: drills[2] 有重複選項（會出現兩個正解）
XX: drills[3] 選項少於 3 個
XX: drills[0] 的選項含 Markdown 記號（不會被渲染）：`erase`
```

只要有人再新增打字題、或把答案打錯一個字，**內容 CI 直接擋下**。

## 7. 沒有改的東西（刻意）

- **複習卡**（FSRS 排程的那些）：它們是「翻卡自我評分」—— 先看問題、想一下、
  顯示答案、再自評 1–4 級。**沒有打字**，所以不在這次範圍。
  若你也想把複習卡改成選擇題，那是另一個設計題（會失去「回想」的效果）。
- **程式碼練習**：那是產品的核心，必須真的寫程式。

若「打字題」還包括別的地方（例如你看到的畫面不是我以為的那個區塊），
請告訴我是哪一節、哪一行文字。
