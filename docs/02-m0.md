## 1. 現在有什麼

```
cppforge/
├─ app/
│  ├─ server/          Node HTTP 服務（零框架）
│  │  ├─ index.mjs       路由、靜態檔、API
│  │  ├─ grading.mjs     評測引擎（6 種 grader）
│  │  ├─ content.mjs     內容載入 / 驗證 / 解鎖
│  │  ├─ db.mjs          node:sqlite 進度儲存
│  │  ├─ doctor.mjs      環境檢查 + 一鍵安裝工具鏈
│  │  ├─ config.mjs      路徑與設定（ASCII 守衛）
│  │  └─ verify-content.mjs  內容 CI（CLI）
│  ├─ web/             三欄 UI（原生 ES module + Monaco）
│  │  ├─ index.html / styles.css / app.js / md.js
│  └─ content/         10 個節點（L0×3、L1×7）
├─ lib/                共用 C++ 資產（沙箱、洩漏檢查、測試框架、路徑解析）
├─ poc/                已封存的技術驗證（保留可重跑）
└─ docs/
```

啟動：

```powershell
cd cppforge
node app/server/index.mjs      # → http://127.0.0.1:4173
```

若你的家目錄含非 ASCII 字元（本專案 workspace 就是），需先指定安裝路徑：

```powershell
$env:CPPFORGE_HOME = "C:\CppForge"    # 必須是純英文路徑
node app/server/index.mjs
```

## 4. 六種 grader（實際可用）

| grader | 用途 | 一節耗時 |
|---|---|---|
| `compile` | `-Wall -Wextra -Wpedantic -Werror` 全綠 | ~0.7 s |
| `unit_test` | 隱藏測試（`cf_test.hpp`） | ~1.3 s |
| `io_match` | stdin/stdout 逐字比對 | ~1.1 s |
| `runtime_safety` | `_GLIBCXX_DEBUG` + 洩漏攔截 | ~3 s |
| `static_rules` | 禁用寫法（含行號） | <5 ms |
| `analyzer` | `-fanalyzer`（非阻塞，含 CWE） | ~0.6 s |

一次完整評測（含 2 次編譯）約 **2 秒**；開啟 `runtime_safety` 約 **5 秒**。
比 POC 的 7 秒快，因為節點只宣告「真的需要的 grader」。

## 5. 與框架文件的三個偏離（附理由）

| 框架原本寫 | 實際做法 | 理由 |
|---|---|---|
| React + Vite + TypeScript | 原生 ES module + 字串模板（`app.js` 一個檔案） | M0 要驗證的是學習閉環，不是打包工具。無建置步驟 = 改一行就生效，除錯成本最低。要換框架只需重寫 `web/`，API 契約不變。 |
| better-sqlite3 | **`node:sqlite`（Node 24 內建）** | better-sqlite3 需要 node-gyp + MSVC，這台機器沒有 MSVC。內建模組零安裝、零編譯。 |
| Monaco 用 bundler 打包 | 直接服務 `node_modules/monaco-editor/min/vs`（AMD loader） | 免打包。已精簡到 24 MB（移除 dev/esm/maps）；載入失敗時 UI 自動退回 `textarea`，不會白畫面。 |

## 8. 已知限制

1. **本專案的 workspace 路徑含中文**，所以正式安裝位置一定是 `%LOCALAPPDATA%\CppForge`；`doctor` 會檢查並在非 ASCII 時直接拒絕。
2. 評測是**單執行緒同步**的：送出一份作業時服務會忙 2–5 秒。單人使用無妨，多使用者要改成佇列。
3. ~~UI 沒有做瀏覽器端自動測試~~ → **已補上**（見 `03-m1.md` §5）：`app/test/dom-smoke.mjs` 用 DOM shim 真的執行 `app.js`，涵蓋啟動、渲染、送出評測、環境檢查、錯誤圖鑑。仍**不能**驗證版面與 Monaco 的實際渲染 —— 那部分仍需人眼確認。
4. `node:sqlite` 在 Node 24 仍是實驗性 API，未來版本可能改名（會影響 `db.mjs` 一個 import）。
