## 1. 先量測問題（不是憑感覺）

上一輪做完 `operator<<`，我先量了「現在的失敗訊息有多難讀」，把 L2.05 起始碼的訊息印出來：

```
· +=：兩軸都要更新 — tests.cpp:19  期望 a.y() == 6 但兩者不相等
· operator<<：格式必須是 (x, y) — tests.cpp:63  期望 os.str() == std::string("(1, 2)") 但兩者不相等
```

**「兩者不相等」等於沒說**。學員知道 `a.y()` 不是 6，但不知道它是 4、2 還是 -999。
這一條訊息就足以讓他自己除錯，卻被丟掉了。

## 2. 改了什麼

`lib/cf_test.hpp` 從 123 行增加到約 210 行，三個能力：

### （a）有 `operator<<` 就印出實際值

```cpp
template <class T>
concept streamable = requires(std::ostream& os, const T& v) { os << v; };
```

用 C++20 的 `requires` 偵測「這個型別能不能被 `<<`」。能，就串流成字串；不能，就退回原本的條件字串。

**改動前後對照**（同一份起始碼、同一批測試）：

| 測試 | 改動前 | 改動後 |
|---|---|---|
| `+=` 兩軸 | `期望 a.y() == 6 但兩者不相等` | `a.y() == 6 不成立（實際 2，期望 6）` |
| `<<` 格式 | `期望 os.str() == std::string("(1, 2)") 但兩者不相等` | `os.str() == std::string("(1, 2)") 不成立（實際 1 2，期望 (1, 2)）` |
| `==` y 軸 | `Vec2(1, 2) == Vec2(1, 9) == false 但兩者不相等` | `Vec2(1, 2) == Vec2(1, 9) == false 不成立（實際 true，期望 false）` |

第三列特別有意義：`Vec2` 自己的 `operator<<` 讓訊息變成 `Vec2(1, 2)` —— 前提是**那個節點有教 `<<`**。教學投資在這裡兌現。

### （b）沒有 `<<` 的型別要優雅退化

`std::vector<int>` 沒有 `operator<<`。若硬要印會編不過，所以：

```cpp
std::vector<int> a{1, 2}, b{1, 3};
CF_EXPECT_EQ(a, b);
// → main.cpp:21  a == b 不成立
```

只印條件，不印「實際 <無法列印>，期望 <無法列印>」這種噪音。判斷方式是編譯期 concept，**不是**執行期比較字串。

### （c）enum 與浮點

- `enum class` 沒有 `<<`，但除錯時看到數值有用 → 印成 `enum(0)`。
- 新增 `CF_EXPECT_NEAR(actual, expected, eps)`，訊息是 `兩者差距超過 1e-09（實際 0.3，期望 0.5）`。
  L2.05 的兩個 `length()` 測試已改用這個，取代原本手寫的 `std::fabs(...) < 1e-9`。

## 3. 驗證過程中抓到的真 bug

我寫了一個臨時檢查（四種型別各跑一次），第一次執行就編不過：

```
error: no matching function for call to 'add_near_failure(...)'
  candidate 1: template<class A, class B, class E> ...
```

原因：`add_near_failure` 的 template 參數宣告了 `A, B, E`，但 `E` 從未出現在函式參數裡 —— **無法推導**，
所以 `CF_EXPECT_NEAR` 完全不能用。拿掉 `E` 就好了。

這件事本身值得記錄：**新加的巨集如果沒有立刻被使用，錯誤會潛伏到第一次有人用它才爆**。
所以驗證腳本要刻意把每個分支都跑一次（含「不該編過」的反向案例）。

四種路徑的最終輸出：

```
[FAIL] 有 << 的型別：印出實際值
       main.cpp:15  a == b 不成立（實際 P(1,2)，期望 P(1,9)）
[FAIL] 沒有 << 的型別：優雅退化
       main.cpp:21  a == b 不成立
[FAIL] enum 也會印出數值
       main.cpp:25  Color::Red == Color::Green 不成立（實際 enum(0)，期望 enum(1)）
[FAIL] 浮點：NEAR 的訊息
       main.cpp:29  0.1 + 0.2 ≈ 0.5  兩者差距超過 1e-09（實際 0.3，期望 0.5）
```
